Questions

Asked, and answered plainly.

If an answer here sounds like a limitation, it is one. Every claim on this page describes what the shipped code does, not what a marketing line would prefer.

Blocking

Does FOCUS block all ads?

No, and no filter list does. It blocks 135 ad rules and 62 tracker rules covering the large exchanges, analytics SDKs and conversion pixels, plus sponsored slots hidden by site-specific selectors on nine major platforms. Ads served from the same domain as the page, or inside a video stream, get through.

It also hides feed ads but cannot skip YouTube pre-roll or mid-roll ads. Skipping in-player video needs techniques this build does not ship, and FOCUS does not claim to.

A site broke while FOCUS was on. What now?

Pause the site from the popup. That adds it to your allowlist, which outranks every filter with a much higher priority — so the site behaves as if FOCUS were not installed. If the breakage came from cosmetic hiding rather than network rules, switch the mode from Complete to Optimal and retest before blaming the whole extension.

Why didn’t it block a site I expected it to?

The betting list is hand-curated: 63 sportsbooks, casinos and poker rooms. It is not a general-purpose blocklist and does not grow by itself. Similarly, a tracker absent from the packaged list is not blocked. The filters are readable text inside the package — no hidden remote updates.

Does a bigger mode slow the browser down?

Network blocking is done by the browser’s declarative rules engine, not by a script watching your traffic, so there is no per-request JavaScript cost. The only per-page work is a stylesheet in Complete mode and the reels check on five domains. Beyond that, FOCUS has no measurable overhead to report because it never runs on other pages.

Reels and Shorts

Why is reels blocking off right after install?

Because it is opt-in. The reels blocker changes what a page shows, so nothing is hidden until you approve it on the permission screen that opens after installation. That screen lists the five supported sites and what happens on each. Decline and you keep ad filtering only.

Which platforms are covered?
  • Instagram — Reels tab, reels routes, suggested reels in the feed
  • Facebook — Reels tab and reel watch routes
  • YouTube — Shorts shelf and the Shorts player
  • TikTok — the For You feed
  • Snapchat — Spotlight

Opening a reel route shows a pause screen with the time, a link back to the feed, and an optional five-minute pass. The rest of each app keeps working.

Will it log me out of Instagram or YouTube?

No. An earlier build reloaded the site root to escape a reel, which could strand you on a signed-out shell. “Back to feed” now uses the site’s own history, so you stay signed in. As a second guard, FOCUS checks whether a page is a login or auth route — and whether a password field is actually rendered — and never covers it.

Can I turn reels blocking off after approving it?

Yes, from the popup or the settings page, per platform or entirely. Consent is stored separately from the switches, so it is never inferred: an extension update cannot switch the blocker back on for someone who declined or withdrew.

Privacy and permissions

Does FOCUS send anything anywhere?

No. The extension has no server and makes no network requests of its own. Settings, allowlist and the daily counter live in chrome.storage.local — your browser profile, not your Google account. The Android app declares no INTERNET permission at all, so it is technically incapable of sending data.

Can it read my passwords, messages or cookies?

No. It requests storage, declarativeNetRequest and tabs, and no webRequest, cookies, history, scripting, downloads or identity. Request bodies, headers and cookies are never read. It does not inspect page content or form fields.

Why does the Android app need Usage access?

It is the only Android API that reveals which app is in the foreground. FOCUS reads recent activity-resumed events in a rolling window of a few seconds and compares the package name with your blocklist. Those events are never written to disk. Without that permission, detection cannot work, and the app says so instead of pretending.

Why does the Android app cover the whole app instead of just the feed?

Android gives no public API for one app to read or filter another app’s screens, and no way to target a specific tab inside Instagram or YouTube. Covering the app you chose is the honest version of what is possible. It also cannot stop you from force-stopping it — that escape hatch is deliberate.

Availability

Where can I install FOCUS?

Neither product is public yet. The extension is in review for the Chrome Web Store; the Android app is built and tested but not published to Google Play. This site will link to both listings the moment they are live, and it will not show an install button before that is true.

Does it work in Edge, Brave or Opera?

Any Chromium browser that supports Manifest V3 and the declarative rules API should run it — Edge, Brave, Vivaldi, Opera. Firefox has a different extension platform and is not supported by this build.

Can I use the extension and the Android app together?

Yes. They are separate products with separate settings and separate storage. Nothing is synced between them, because neither has a server or a sync backend.

Is it free?

Yes — free, with no account, no subscription and no ads inside either product. There is nothing to upsell, so there is no reason to weaken a block behind a paywall.
