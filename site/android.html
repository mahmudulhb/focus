Android app · v1.0.0 · in preparation

A pause screen for your phone.

Pick the apps that pull you in, start a session, and FOCUS covers them for the length you chose. Between sessions, Reels Guard keeps the short-form apps closed.

What it does

Sessions

15 to 90 minutes

Start a focus session and opening a blocked app shows a full-screen pause screen with the time left, a “Back to focus” button, and an optional five-minute pass.

All day

Reels Guard

Keep the same app list blocked outside sessions. One switch, no schedule to maintain, and it survives a reboot if it was on when the phone shut down.

Local

Today and streak

Focused time, interruptions and a daily streak, stored on the phone. Reset today’s counters any time; the blocklist and streak stay.

Why it blocks the whole app

Android does not let one app read or filter another app’s screens, and there is no public API for reaching into Instagram’s or YouTube’s Reels tab. So FOCUS does what is actually possible: it covers the entire app you chose. It is honest about the trade — the whole app goes quiet, not just the feed.

It also cannot stop you from force-stopping it or uninstalling it. That is deliberate: an escape hatch you control beats software that fights you.

Permissions, and exactly what each is for

Usage access
The only Android API that reveals which app is in front. FOCUS reads recent activity-resumed events in a rolling window of a few seconds and compares the package name with your blocklist. Events are never stored.
Display over other apps
Draws the pause screen over the app you chose to block. It never covers an app that is not on your list, and it does not read the screen.
Notifications
The single ongoing notification Android requires for the background monitor.
Battery exception (optional)
Keeps blocking alive with the screen off on aggressive battery managers.

No accessibility service, no VPN, no QUERY_ALL_PACKAGES, and no INTERNET permission — the app cannot send data anywhere.
